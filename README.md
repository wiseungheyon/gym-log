# 🏋️ 헬스 운동 기록 & 1RM 계산기

운동 기록을 저장하고 1RM(1회 최대 중량), 목표별 훈련 중량, 총 볼륨, 소모 칼로리를 계산해 주는 웹 프로그램입니다.
객체지향프로그래밍 수업에서 1주차에 만든 **C++ 콘솔 프로그램**을 2주차에 생성형 AI와 **HTML / CSS / JavaScript**로 웹 버전으로 바꿨고, 3주차에 GitHub Pages로 배포했습니다.

## 🔗 바로 사용하기

👉 https://wiseungheyon.github.io/gym-log/

PC와 스마트폰 브라우저에서 모두 사용할 수 있고, 설치할 필요가 없습니다.

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 내 정보 | 체중을 입력하면 소모 칼로리 계산에 사용됩니다 |
| 근력 운동 추가 | 운동 이름, 무게, 횟수, 세트 입력 |
| 유산소 운동 추가 | 운동 이름, 시간(분), 강도(가볍게 / 보통 / 강하게) 입력 |
| 운동 기록 | 근력·유산소를 색으로 구분해서 보여주고, 근력 운동은 예상 1RM도 표시. 기록 삭제와 필터 기능 |
| 운동 통계 | 운동 개수, 총 볼륨, 소모 칼로리, 1RM이 가장 높은 운동 |
| 1RM 계산 | 들었던 무게와 횟수로 1RM을 계산하고, 목표(근력 / 근비대 / 근지구력)별 추천 중량을 막대그래프로 표시 |
| 자동 저장 | 브라우저(localStorage)에 저장되어 새로고침해도 기록이 남습니다 |

## 📖 사용 방법

1. **내 정보**에 체중을 입력합니다.
2. **운동 추가**에서 `근력 운동` / `유산소 운동` 탭을 고르고 값을 입력한 뒤 **추가하기**를 누릅니다.
3. 오른쪽(스마트폰은 아래쪽) **운동 기록**과 **운동 통계**가 바로 바뀝니다.
4. **1RM 계산**에 무게와 횟수를 넣고 훈련 목표를 고른 뒤 **계산하기**를 누르면 추천 중량이 나옵니다.

예시 입력 (체중 75kg)

- 벤치 프레스 80kg × 8회 × 4세트
- 스쿼트 100kg × 5회 × 5세트
- 러닝머신 30분, 보통

→ 총 볼륨 **5,060kg**, 소모 칼로리 **375kcal**, 최고 1RM **스쿼트 116.7kg**

## 🧮 계산 방법

- **1RM (Epley 공식)**: `무게 × (1 + 횟수 ÷ 30)`
- **볼륨**: `무게 × 횟수 × 세트`
- **칼로리 (MET 공식)**: `MET × 체중(kg) × 시간(h)`
  - 근력 운동: MET 5.0, 1세트당 휴식 포함 2분
  - 유산소: 가볍게 3.5 / 보통 7.0 / 강하게 10.0

## 🧱 구조 (1주차 C++ → JavaScript)

1주차 C++ 프로그램의 클래스 구조를 그대로 JavaScript 클래스로 옮겼습니다.

```
Exercise (기본 클래스)
 ├─ StrengthExercise  근력 운동: 무게, 횟수, 세트 / calc1RM()
 └─ CardioExercise    유산소 운동: 시간, 강도
WorkoutLog            운동 기록 목록 관리, 통계 계산, 저장
```

| C++ (1주차) | JavaScript (2주차) |
|---|---|
| `class StrengthExercise : public Exercise` | `class StrengthExercise extends Exercise` |
| 순수 가상 함수 `= 0` | 기본 클래스에서 호출하면 오류 → 자식 클래스에서 재정의 |
| `dynamic_cast` | `instanceof` |
| `vector<Exercise*>` | 배열 `[]` |
| 콘솔 메뉴 `switch` | 버튼, 탭 |
